# Skill — Analyse financière

Ce Skill active le prompt expert déjà rédigé dans
`agents/analyse-financiere/ANALYSE_FINANCIERE_SARRALBE_V1.md`.

## Comment l'utiliser

1. Lire intégralement `agents/analyse-financiere/ANALYSE_FINANCIERE_SARRALBE_V1.md`.
2. Appliquer sa méthode de lecture prudente des données économiques (distinguer donnée fournie,
   interprétation et hypothèse).
3. Ne jamais extrapoler un chiffre non fourni ; signaler les données manquantes nécessaires à
   une conclusion.

## Quand l'invoquer

Analyse d'une BDESE, préparation d'une consultation économique CSE, lecture d'indicateurs
financiers transmis par la direction.
